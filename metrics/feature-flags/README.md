# Feature Flags Metrics

Artifacts in this directory are generated by `npm run flags:stale` / `.github/workflows/flags-stale.yml`. They keep a lightweight history of stale flag counts so we can hook Grafana widgets and /ops dashboards into the same source of truth.

- `stale-report.json` — summary of every flag whose `sunset_date` tag lives in the past, plus a list of flags missing sunset metadata.

Do not edit generated files by hand; re-run the script instead or wait for the scheduled workflow to refresh the snapshot. Downstream dashboards ingest this JSON and expect the `schemaVersion` + field names above to remain backward-compatible.
